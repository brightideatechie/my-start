# My Start — Implementation Roadmap

1. Regression tests for current HTML, Perchance and JSON export.
2. Layout registry and reusable responsive layout regions; eight core families first, 60 catalog entries.
3. Widget registry, JSON schemas, local widgets, lifecycle cleanup, and interactive wizard.
4. Profile management and browser extension for tab-group awareness.
5. Sandboxed Perchance widget embedding and user-reviewed native adapters.
6. Read-only SearXNG, Plex, Home Assistant, email and other data connectors.
7. AI assistant for configuration suggestions; no automatic privileged actions.
8. Authenticated local Hermes companion with verified MCP/skills API, capability allowlists and audit logs.
9. Optional speech and browser automation with explicit per-action consent.
10. Remote infrastructure management only after security review; financial and advertising integrations as separate regulated workstreams.

Definition of done per milestone: unit tests, browser tests, accessibility, threat review, documentation, and clear indication of unsupported functions.
